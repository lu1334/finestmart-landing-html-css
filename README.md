# 🛒 FinestMart Landing (HTML & CSS)

Hola 👋 soy **Sandy**, y en este proyecto continué practicando **maquetación con HTML y CSS**.  
Quise recrear una landing orientada a un supermercado digital para trabajar grids de productos y mensajes claros.

- A organizar correctamente el HTML con secciones bien definidas.  
- A usar **Flexbox** y **Grid** para distribuir los elementos.  
- A aplicar **colores, tipografía y jerarquías visuales** de forma coherente.
